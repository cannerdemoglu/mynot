ApexCharts Rehberi

Bu rehberde ApexCharts'ı hiç bilmediğini varsayarak başlıyoruz. HTML'e nasıl eklenir, CSS ile nasıl uyumlu hale gelir, PHP ve MySQL'den gelen veri nasıl grafiğe dönüşür; hepsini adım adım göreceğiz.

Bu sayfa nasıl okunur?

Her bölümde önce açıklama, sonra kod, sonra da kodun canlı sonucu var. Kodları "Kopyala" düğmesiyle alıp kendi dosyanda deneyebilirsin. Soldaki menüden istediğin bölüme atlayabilirsin.

1.ApexCharts Nedir?

ApexCharts, web sayfalarına grafik (çizgi, sütun, pasta, halka vb.) eklemeni sağlayan ücretsiz bir JavaScript kütüphanesidir.

"Kütüphane" demek, başkalarının yazdığı hazır kod demektir. Grafiği sıfırdan çizmek yerine ApexCharts'a "şu verilerle, şu renkte, şu türde bir grafik çiz" dersin, o da senin yerine çizer.

Neden ApexCharts?

  • Kolay: Birkaç satır kodla grafik çıkar.
  • Animasyonlu: Grafikler yüklenirken ve güncellenirken yumuşak animasyon yapar.
  • Etkileşimli: Fareyle üzerine gelince bilgi kutusu (tooltip) gösterir.
  • Mobil uyumlu: Ekran küçülünce kendini ayarlar.
  • Ücretsiz: MIT lisanslıdır, ticari projelerde de kullanılabilir.

Hangi dilleri bilmen gerekiyor?

DilApexCharts'taki görevi
HTMLGrafiğin duracağı kutuyu (<div>) oluşturur ve kütüphaneyi sayfaya ekler.
CSSGrafiğin etrafındaki kartı, boşlukları, genişliği ayarlar.
JavaScriptGrafiği oluşturan asıl kısım. Ayarlar ve veriler burada yazılır.
PHPVeritabanından veriyi alıp JavaScript'e verir. (İsteğe bağlı)

2.Kurulum

ApexCharts'ı kullanmanın en kolay yolu CDN'dir. CDN, dosyayı internetteki bir sunucudan doğrudan sayfana çekmek demek. Hiçbir şey indirmen gerekmez.

Yöntem 1: CDN (önerilen)

Sayfana şu tek satırı eklemen yeterli:

HTML 
<script src="https://cdn.jsdelivr.net/npm/apexcharts@3.54.1/dist/apexcharts.min.js"></script>
İpucu: Sürüm numarası neden yazılı?

Adresteki @3.54.1 kısmı sürümü sabitler. Sürüm yazmazsan kütüphane güncellendiğinde sitenin görünümü bir gün kendiliğinden değişebilir. Sabit sürüm daha güvenlidir.

Bu satırı nereye koymalıyım?

En güvenli yer, </body> etiketinin hemen önüdür. Böylece önce sayfadaki HTML yüklenir, sonra grafik kodu çalışır.

HTML 
<!DOCTYPE html>
<html lang="tr">
<head>
    <meta charset="UTF-8">
    <title>Sayfam</title>
    <link rel="stylesheet" href="style.css">   <!-- CSS burada -->
</head>
<body>

    <!-- Sayfa içeriği burada -->

    <!-- 1) Önce kütüphane -->
    <script src="https://cdn.jsdelivr.net/npm/apexcharts@3.54.1/dist/apexcharts.min.js"></script>

    <!-- 2) Sonra senin grafik kodun -->
    <script src="grafik.js"></script>
</body>
</html>
Dikkat: Sıralama önemli!

Kütüphane satırı, senin grafik kodundan önce gelmeli. Aksi halde tarayıcı ApexCharts is not defined hatası verir, çünkü henüz kütüphaneyi tanımıyordur.

Yöntem 2: Dosyayı indirip projeye koymak

İnternet olmadan da çalışsın istiyorsan:

  1. https://cdn.jsdelivr.net/npm/apexcharts@3.54.1/dist/apexcharts.min.js adresini tarayıcıda aç.
  2. Sayfaya sağ tıklayıp Farklı Kaydet de ve projende örneğin main/js/apexcharts.min.js olarak kaydet.
  3. Script satırını yerel dosyayı gösterecek şekilde değiştir:
HTML 
<script src="main/js/apexcharts.min.js"></script>

Yöntem 3: npm (ileri seviye)

React, Vue gibi araçlar veya bir derleyici (Vite, Webpack) kullanıyorsan:

Terminal 
npm install apexcharts

Senin projen düz PHP olduğu için Yöntem 1 (CDN) en uygunu. Projedeki index.php de bu yöntemi kullanıyor.

3.İlk Grafiğin

Bir grafik oluşturmak için her zaman 3 şey gerekir:

  1. Bir kutu: Grafiğin çizileceği boş bir <div>.
  2. Ayarlar: Grafiğin türü, verisi, renkleri vb. (bir JavaScript nesnesi).
  3. Çizim komutu: new ApexCharts(kutu, ayarlar).render()

Tam örnek

Aşağıdaki kodu ilk-grafik.html adıyla kaydedip tarayıcıda açarsan grafiği görürsün:

HTML + JavaScriptilk-grafik.html 
<!DOCTYPE html>
<html lang="tr">
<head>
    <meta charset="UTF-8">
    <title>İlk Grafiğim</title>
</head>
<body>

    <!-- 1) Grafiğin çizileceği kutu -->
    <div id="grafik"></div>

    <script src="https://cdn.jsdelivr.net/npm/apexcharts@3.54.1/dist/apexcharts.min.js"></script>
    <script>
        // 2) Ayarlar
        const ayarlar = {
            chart: {
                type: "line",     // grafik türü: çizgi
                height: 300       // yükseklik (piksel)
            },
            series: [{
                name: "Görev",
                data: [3, 5, 2, 8, 6, 4, 7]
            }],
            xaxis: {
                categories: ["Pzt", "Sal", "Çar", "Per", "Cum", "Cmt", "Paz"]
            }
        };

        // 3) Grafiği oluştur ve çiz
        const grafik = new ApexCharts(document.querySelector("#grafik"), ayarlar);
        grafik.render();
    </script>

</body>
</html>
Sonuç

Satır satır ne oldu?

KodAnlamı
<div id="grafik">Boş bir kutu. ApexCharts grafiği bunun içine çizecek. id sayesinde JavaScript bu kutuyu bulabiliyor.
const ayarlar = { ... }Bütün ayarları tutan bir JavaScript nesnesi (object).
chart.typeGrafik türü. "line" çizgi, "bar" sütun, "pie" pasta vb.
seriesGrafiğin verisi. Bir dizi (array) içinde bir veya daha fazla seri olabilir.
xaxis.categoriesYatay eksende yazacak etiketler. Sayıları data ile aynı olmalı (burada 7'şer tane).
document.querySelector("#grafik")Sayfadaki id="grafik" olan kutuyu bulur.
new ApexCharts(...)Grafik nesnesini oluşturur, ama henüz çizmez.
.render()Grafiği ekrana çizer.
Not: # işareti ne?

CSS'te olduğu gibi #grafik "id'si grafik olan eleman" demek. Bir class seçmek isteseydin .grafik yazardın.

4.Ayarlar (options) Yapısı

ApexCharts'ta her şey tek bir ayar nesnesiyle kontrol edilir. Bu nesne iç içe "çekmecelerden" oluşur. Her çekmece grafiğin bir bölümünü ayarlar.

JavaScript — Genel iskelet 
const ayarlar = {
    chart:      { },   // grafiğin kendisi: tür, yükseklik, animasyon, font
    series:     [ ],   // VERİ
    xaxis:      { },   // yatay eksen (alt)
    yaxis:      { },   // dikey eksen (sol)
    colors:     [ ],   // renkler
    title:      { },   // başlık
    stroke:     { },   // çizgi kalınlığı / şekli
    fill:       { },   // iç dolgu (düz renk, gradyan)
    dataLabels: { },   // değerlerin grafik üstünde yazması
    markers:    { },   // çizgideki noktalar
    grid:       { },   // arka plandaki ızgara çizgileri
    legend:     { },   // seri isimlerinin listesi (gösterge)
    tooltip:    { },   // üzerine gelince çıkan kutu
    plotOptions:{ },   // türe özel ayarlar (bar, pie, radialBar…)
    responsive: [ ],   // ekran boyutuna göre farklı ayarlar
    theme:      { }    // açık / koyu tema
};
İpucu: Hepsini yazmak zorunda değilsin

Yazmadığın her ayar için ApexCharts kendi varsayılan değerini kullanır. Bir grafik için aslında sadece chart.type ve series yeterlidir.

series: Veri nasıl yazılır?

series her zaman bir dizidir (köşeli parantez [ ]). İçinde her seri bir nesnedir:

JavaScript — İki seri 
series: [
    { name: "Eklenen",    data: [4, 6, 3, 7, 5, 8, 6] },
    { name: "Tamamlanan", data: [2, 4, 3, 5, 4, 6, 5] }
]
Sonuç
Dikkat: Pasta ve halka grafiklerde series farklı!

pie, donut ve radialBar türlerinde series düz bir sayı dizisidir, isimler ise labels ile verilir:

series: [44, 33, 23], labels: ["İş", "Okul", "Ev"]

Veriyi x-y çiftleri olarak yazmak

Etiketleri ayrı yazmak yerine her noktayı { x, y } şeklinde de verebilirsin:

JavaScript 
series: [{
    name: "Görev",
    data: [
        { x: "Pzt", y: 3 },
        { x: "Sal", y: 5 },
        { x: "Çar", y: 2 }
    ]
}]

Tarih eksenli veri

Veriler tarihe bağlıysa xaxis.type: "datetime" kullanılır. ApexCharts tarihleri kendisi biçimlendirir:

JavaScript 
xaxis: { type: "datetime" },
series: [{
    name: "Görev",
    data: [
        { x: "2026-11-01", y: 3 },
        { x: "2026-11-02", y: 5 },
        { x: "2026-11-03", y: 2 }
    ]
}]

Yüzde göstermek için idealdir. Değer 0 ile 100 arası olmalıdır.

                    fontSize: "28px",

6.Renk, Çizgi, Etiket

Bu bölümde grafiğin görünümünü değiştiren en önemli ayarları göreceğiz. Hepsini tek bir örnekte topladık:

JavaScript 
new ApexCharts(document.querySelector("#sekilli"), {
    chart: {
        type: "area",
        height: 280,
        toolbar: { show: false },               // sağ üstteki menüyü gizle
        fontFamily: "Poppins, sans-serif"       // yazı tipi
    },
    series: [{ name: "Görev", data: [3, 5, 2, 8, 6, 4, 7] }],
    xaxis: { categories: ["Pzt", "Sal", "Çar", "Per", "Cum", "Cmt", "Paz"] },

    colors: ["#3955A2"],                        // ana renk

    title: {
        text: "Haftalık Görevler",
        style: { fontSize: "16px" }
    },

    stroke: {
        curve: "smooth",                        // "straight" | "smooth" | "stepline"
        width: 3                                // çizgi kalınlığı
    },

    fill: {
        type: "gradient",                       // "solid" | "gradient" | "pattern"
        gradient: {
            opacityFrom: 0.5,                   // üstte ne kadar dolu
            opacityTo: 0                        // altta ne kadar şeffaf
        }
    },

    markers: { size: 5 },                       // noktalar

    dataLabels: { enabled: false },             // sayı etiketleri kapalı

    grid: {
        borderColor: "#e0e0e0",
        strokeDashArray: 4                      // kesikli ızgara
    },

    tooltip: {
        y: {
            formatter: function (deger) { return deger + " görev"; }
        }
    }
}).render();

formatter nedir?

formatter, bir sayının ekranda nasıl yazılacağını belirleyen küçük bir fonksiyondur. Değeri alır, istediğin metni döndürürsün:

JavaScript 
// Uzun yazım
formatter: function (deger) {
    return deger + " görev";
}

// Kısa yazım (ok fonksiyonu) — aynı şey
formatter: deger => deger + " görev"

// Yüzde
formatter: deger => Math.round(deger) + "%"

// Para
formatter: deger => deger.toLocaleString("tr-TR") + " ₺"

Koyu tema

Senin siten koyu renkli olduğu için bu önemli. Koyu arka planda grafiğin de koyu temada olması gerekir:

JavaScript 
{
    chart: {
        type: "area",
        background: "transparent",          // grafik kendi arka planını çizmesin, CSS'teki görünsün
        foreColor: "rgba(255,255,255,0.5)"  // eksen yazıları açık renk
    },
    theme: { mode: "dark" },                // tooltip vb. koyu olsun

}

7.CSS ile Bağlantı

Bu bölüm çok önemli. ApexCharts grafiği JavaScript ile çizer ama grafiğin nerede, ne genişlikte, hangi kartın içinde duracağını CSS belirler.

7.1 CSS dosyasını bağlamak

CSS dosyası her zaman <head> içinde <link> ile bağlanır:

HTML 
<head>
    <meta charset="UTF-8">
    <link rel="stylesheet" href="main/css/main.css">
</head>

Senin projende index.php zaten main/css/main.css dosyasını bu şekilde bağlıyor.

7.2 Genişlik ve yükseklik: kim belirler?

Kim belirler?Nasıl?
GenişlikCSS (kutunun genişliği)Grafik, içinde bulunduğu div'in genişliğinin %100'ünü kaplar. Kutu 500px ise grafik de 500px olur.
YükseklikJavaScriptchart.height: 300 ile piksel olarak yazılır.
CSS — Genişliği CSS ile sınırlamak 
#grafik {
    max-width: 600px;    /* grafik en fazla 600px olsun */
    margin: 0 auto;      /* ortala */
}
İpucu: Yüksekliği de CSS'ten vermek

Grafiğin yüksekliğini CSS'ten kontrol etmek istersen JavaScript'te height: "100%" yaz ve kutuya CSS'te bir yükseklik ver. Ana sayfadaki dalgalar böyle yapıldı:

.hero-waves { height: 42%; } + chart: { height: "100%" }

7.4 CSS değişkenlerini (renkleri) grafikte kullanmak

Senin main.css dosyanda renkler değişken olarak tanımlı:

CSSmain/css/main.css 
:root {
    --bgColor: #1C1B1D;
    --Blue: #3955A2;
}

ApexCharts CSS değişkenini doğrudan anlamaz (colors: ["var(--Blue)"] çalışmaz). Ama JavaScript ile değişkenin değerini okuyup verebilirsin. Böylece rengi değiştirmek istediğinde sadece CSS'i değiştirmen yeter:

JavaScript 
// CSS'teki --Blue değişkenini oku
const stil = getComputedStyle(document.documentElement);
const mavi = stil.getPropertyValue("--Blue").trim();   // "#3955A2"

new ApexCharts(document.querySelector("#grafik"), {
    chart: { type: "line", height: 250 },
    colors: [mavi],                                     // CSS'ten gelen renk
    series: [{ name: "Görev", data: [3, 5, 2, 8] }]
}).render();

7.5 ApexCharts'ın kendi parçalarını CSS ile değiştirmek

ApexCharts çizdiği her parçaya bir class verir. Bu class'ları CSS'te hedefleyerek ince ayar yapabilirsin. Bazen !important gerekir, çünkü ApexCharts bazı stilleri doğrudan elemanın üzerine yazar.

CSS 
/* Tooltip (üzerine gelince çıkan kutu) */
.apexcharts-tooltip {
    border-radius: 10px !important;
    box-shadow: 0 8px 24px rgba(0, 0, 0, 0.4) !important;
}

/* Gösterge (legend) yazıları */
.apexcharts-legend-text {
    font-size: 13px !important;
}

/* Eksen yazıları */
.apexcharts-xaxis-label,

10.PHP + MySQL Verisi

Adım 6: Boş günleri 0 ile doldurmak

Yukarıdaki sorguda hiç görev eklenmeyen günler hiç gelmez (örnekte 3 Kasım yok). Grafik bu günü atlar ve yanıltıcı olur. Çözüm: PHP'de son X günün hepsini 0 olarak hazırlayıp, gelen verilerle doldurmak:

    $veri[$tarih] = 0;
}

     FROM tasks

Adım 7: Sadece giriş yapan kullanıcının verisi

Her kullanıcı kendi grafiğini görsün istiyorsan, task.php'de olduğu gibi oturumdaki kullanıcı numarasını kullanırsın. Kullanıcıdan gelen değerler sorguya her zaman prepared statement ile eklenmelidir:

Güvenlik: SQL Injection

11.AJAX ile Veri Çekmek

Önceki bölümde veri, sayfa yüklenirken PHP tarafından sayfaya gömüldü. Diğer yol: sayfa açıldıktan sonra JavaScript'in ayrı bir PHP dosyasından veriyi istemesi. Buna AJAX denir. Projendeki task_system.js dosyası da görev tamamlarken bu yöntemi (fetch) kullanıyor.

Ne zaman AJAX?

  • Sayfa yenilenmeden grafiğin güncellenmesini istiyorsan.
  • "Son 7 gün / Son 30 gün" gibi filtre düğmeleri yapacaksan.
  • Kullanıcı görev tamamlayınca grafik anında değişsin istiyorsan.

Adım 1: Sadece JSON döndüren PHP dosyası

PHPsystem/chart_data.php

$userID = $_SESSION["u_ID"];
$gun    = isset($_GET["gun"]) ? (int) $_GET["gun"] : 7;     // ?gun=30 gibi
$gun    = max(1, min($gun, 90));                           // 1 ile 90 arasında tut

$veri = [];
for ($i = $gun - 1; $i >= 0; $i--) {
    $veri[date("Y-m-d", strtotime("-$i day"))] = 0;
}

$aralik = $gun - 1;
$stmt = $conn->prepare(

     FROM tasks

     GROUP BY DATE(createdAt)"

$stmt->bind_param("ii", $userID, $aralik);
$stmt->execute();
$sonuc = $stmt->get_result();

    if (isset($veri[$satir["gun"]])) {
        $veri[$satir["gun"]] = (int) $satir["adet"];
    }

echo json_encode([
    "gunler"  => array_keys($veri),

13.Sık Yapılan Hatalar

BelirtiSebepÇözüm
ApexCharts is not defined Kütüphane yüklenmeden grafik kodu çalıştı. Kütüphane <script> satırını kendi kodundan önce koy.
Element not found veya hiçbir şey çizilmiyor Grafik kodu çalıştığında <div> henüz sayfada yok, ya da id yanlış yazılmış. Script'i </body> öncesine koy veya kodu DOMContentLoaded içine al. id'yi kontrol et (# unutma).
Grafik çok küçük / genişliği 0 Grafik, gizli (display: none) bir alanda çizildi. Örn. kapalı bir Bootstrap collapse veya sekme içinde. Alan açıldıktan sonra grafik.render() çağır veya window.dispatchEvent(new Event("resize")) ile yeniden boyutlandır.
Sayfa yatay kayıyor Grid/flex içindeki grafik küçülemiyor. Grafiği saran kutuya min-width: 0 ver.
Aynı grafik iki kere çiziliyor render() iki kez çağrıldı. Güncellemek için updateSeries kullan, yeniden oluşturacaksan önce destroy() çağır.
Eksen değerleri garip, toplamlar yanlış PHP'den sayılar metin olarak geldi ("5"). PHP'de (int) ile çevir.
Türkçe karakterler ç gibi görünüyor json_encode varsayılan olarak kaçış yapar. JSON_UNESCAPED_UNICODE bayrağını ekle. (JavaScript yine de doğru okur, sadece kaynakta çirkin görünür.)
Koyu sitede grafiğin beyaz kutusu var Grafik kendi arka planını çiziyor. chart.background: "transparent" ve theme.mode: "dark".
Pasta grafik boş series nesne dizisi olarak yazıldı. Pie/donut/radialBar'da düz sayı dizisi kullan: [12, 9, 7].
colors: ["var(--Blue)"] çalışmıyor ApexCharts CSS değişkenini çözemez. getComputedStyle ile değeri oku (Bölüm 7.4).
İpucu: Hata ayıklamanın 1 numaralı aracı

Tarayıcıda F12 tuşuna bas ve Console sekmesine bak. Kırmızı yazılar sana neyin yanlış gittiğini söyler. Kodunda console.log(adetler) yazarak PHP'den gelen veriyi de burada görebilirsin.
